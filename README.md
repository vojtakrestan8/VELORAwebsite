# Velora — statická kompatibilní verze

Tento balíček je určený pro hosting bez PHP a otevře se rovnou přes `index.html` — nic se nestahuje.

Editor, registrace a nahrané obrázky fungují jako demo uložené v prohlížeči daného návštěvníka. Skutečné účty, e-mailové ověření a sdílené adresy `/username` nelze na čistě statickém hostingu bezpečně provozovat; pro ně bude potřeba připojit externí databázový backend (např. Supabase nebo Firebase).
